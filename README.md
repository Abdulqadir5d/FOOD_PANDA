# Foodpanda Clone - Complete Website

A comprehensive clone of the Foodpanda website built with HTML, CSS, and JavaScript. This project includes all the essential features of a food delivery platform with separate pages for different functionalities.

## 🚀 Features

### Core Pages
- **Homepage** - Hero section, categories, featured restaurants, and how it works
- **Restaurants Listing** - Browse restaurants with filters, search, and sorting
- **Restaurant Menu** - Individual restaurant pages with menu items and cart functionality
- **Shopping Cart** - Review items, update quantities, and proceed to checkout
- **Checkout** - Complete order form with delivery and payment information
- **User Authentication** - Login and signup pages with form validation

### Key Functionalities
- ✅ Responsive design for all screen sizes
- ✅ Interactive cart management
- ✅ Restaurant filtering and search
- ✅ Menu item ordering with quantity controls
- ✅ Form validation and error handling
- ✅ Local storage for cart and user data
- ✅ Smooth animations and transitions
- ✅ Mobile-friendly navigation

## 🔧 Customization
